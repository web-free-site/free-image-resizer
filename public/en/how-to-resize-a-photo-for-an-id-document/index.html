How to resize a photo for an ID document

Passport, visa, and ID forms usually specify a photo size, background, and how much of the head should appear in the frame. Free Image Resizer can change the pixel size of a picture on your device. It cannot tell you whether a photo will be accepted; only the official instructions can.

Steps

  1. Read the official size and background rules. Look up the current requirements for the country or agency. Note the width and height, the allowed background, and whether a smile or glasses are allowed.
  2. Crop before you resize. Use the crop tool so the face sits in the required position, then set the exact dimensions the form asks for.
  3. Export in the requested format. Download a JPEG or the format named in the instructions. Check the file size limit if the form has one, and compress only if you are still over that limit.
  4. Compare with the checklist. Open the exported image and compare it with the official sample if one is provided. If anything is unclear, use a professional photo service.

Do not invent a size

Requirements differ by country and change over time. This guide does not list official measurements. Always copy them from the application you are filing.

Backgrounds and retouching

A tool that only resizes will not replace a studio background or fix lighting. If the rules require a plain background, start from a photo that already meets that rule.
